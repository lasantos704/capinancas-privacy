Política de Privacidade

Última atualização: 27/10/2026

O Capinanças é um aplicativo de finanças pessoais que funciona 100% no seu aparelho. Não há cadastro, login, servidores ou serviços de nuvem operados por nós.

Dados armazenados

Tudo o que você registra fica armazenado apenas localmente, no dispositivo:

  • lançamentos, categorias e regras de categorização;
  • contas, cartões, faturas, compras parceladas (parcelamentos), dívidas e patrimônio;
  • metas, orçamentos, recorrências, renda sazonal e o calendário do mês — que é apenas uma leitura dos lançamentos já existentes, sem tabela própria;
  • comprovantes anexados (imagem copiada para o armazenamento privado do app, limite de 512 KB por anexo);
  • perfis de importação (as suas receitas de mapeamento de colunas), o selo do arquivo que originou cada lançamento e as configurações do app.

Importação de arquivos

O app pode ler arquivos que você escolher — extrato bancário (OFX/QIF/CSV) ou backup JSON. A leitura acontece no aparelho, pelo seletor de arquivos do próprio sistema, e o resultado é mostrado antes de qualquer gravação. Nenhum arquivo é enviado para nós ou para terceiros, e nada é lido sem você escolher.

Coleta e compartilhamento

Não coletamos, não transmitimos e não compartilhamos seus dados pessoais. Não usamos analytics, rastreamento, publicidade nem SDK de relatório de falhas — nem mesmo telemetria anônima. Nenhuma funcionalidade depende de servidor nosso.

Backup, exportação e diagnóstico

Você pode exportar backup JSON (simples ou protegido por senha, com criptografia local PBKDF2 + AES-256-GCM), CSV (normal e para Excel), o modelo de planilha, um exemplo e o relatório em PDF. Os arquivos saem pelo compartilhamento do sistema, e a ação é sempre iniciada por você. Se uma leitura de dados salvos falhar, o app oferece a exportação de um arquivo de diagnóstico com o conteúdo que estava no aparelho, para que você mesmo analise ou envie a quem for ajudar; ele não é gerado nem enviado automaticamente.

Bloqueio por biometria

O bloqueio do app é opcional. A verificação é feita pelo sistema, com a digital, o rosto ou o PIN do próprio aparelho: não armazenamos biometria nem senha, e o app apenas recebe “deu certo / não deu”.

Permissões

  • Biometria — só se você ativar o bloqueio;
  • Fotos — só para anexar comprovantes: você escolhe a imagem no seletor do próprio sistema, e o app não percorre o resto da sua galeria;
  • Notificações — só para os lembretes que você configurar.

O app não usa localização, não fotografa nem grava vídeo e não tem acesso livre aos arquivos do aparelho: ele só lê o que você escolher.

Notificações

São locais, geradas no aparelho, para lembretes de faturas e recorrências. Nenhum servidor é usado.

Exclusão de dados

Ao limpar os dados do app ou desinstalá-lo, os dados locais são removidos — exporte um backup antes, se quiser guardá-los. Como não temos servidores, não há dados nossos para excluir, e não existe solicitação de cópia ou portabilidade para nós: a exportação é feita pelo próprio app.

Privacy Policy

Last updated: October 27, 2026

Capinanças is a personal finance app that runs 100% on your device. There is no sign-up, login, server or cloud service operated by us.

Data stored

Everything you record is stored locally on the device only:

  • transactions, categories and categorization rules;
  • accounts, cards, invoices, installment plans, debts and net worth;
  • goals, budgets, recurring entries, seasonal income and the monthly calendar — which is only a reading of the transactions you already have, with no table of its own;
  • attached receipts (an image copied into the app's private storage, up to 512 KB per attachment);
  • import profiles (your own column-mapping recipes), the file stamp that records which import produced each transaction, and app settings.

Reading files

The app can read files you choose — a bank statement (OFX/QIF/CSV) or a JSON backup. Reading happens on the device, through the system's own file picker, and the result is shown before anything is saved. No file is sent to us or to any third party, and nothing is read unless you pick it.

Collection and sharing

We do not collect, transmit or share your personal data. We do not use analytics, tracking, advertising or crash-reporting SDKs — not even anonymous telemetry. No feature depends on a server of ours.

Backup, export and diagnostics

You can export a JSON backup (plain or password-protected, using local PBKDF2 + AES-256-GCM encryption), CSV (regular and Excel), the spreadsheet template, a sample file and the PDF report. Files leave through the system share sheet, and the action is always started by you. If reading saved data fails, the app offers a diagnostics file holding what was on the device, so you can inspect it or send it to whoever helps you; it is never generated or sent automatically.

Biometric lock

Locking the app is optional. Verification is done by the operating system with your fingerprint, face or device PIN: we store no biometric data and no password — the app only learns "it worked / it did not".

Permissions

  • Biometrics — only if you turn the lock on;
  • Photos — only to attach receipts: you pick the image in the system's own picker, and the app does not scan the rest of your gallery;
  • Notifications — only for the reminders you set up.

The app does not use location, does not take photos or record video, and has no free access to the device's files: it only reads what you choose.

Notifications

Notifications are local, generated on the device, for invoice and recurring reminders. No server is used.

Data deletion

Clearing app data or uninstalling removes local data — export a backup first if you want to keep it. Since we have no servers, there is no data of ours to delete, and no copy or portability request reaches us: export is a feature of the app itself.
